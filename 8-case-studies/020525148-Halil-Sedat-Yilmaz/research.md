## 1. Microsoft — GitHub Copilot & the Agentic Enterprise

### How They Use AI

Microsoft is globally the company that has and still is investing the most in AI and AI-powered solutions. THey do this with GitHub Copilot and implementation of AI in Microsoft 265.

GitHub Copilot is an AI that aids with programming embedded within editors directly such as VS Code, offering live code suggestions and input-based assistance via a chatbox, all of which together support agnetic coding workflows. For more specific, complex tasks, developers can build custom AI agents tailored for their projects and tasks, allowing developers to automate workflows 
(https://learn.microsoft.com/en-us/power-platform/release-plan/2025wave1/microsoft-copilot-studio/) 
(https://cloudwars.com/cloud/the-agentic-enterprise-arrives-microsofts-copilot-and-agent-breakthroughs-of-2025/).

### Workflow Changes

- Developers can delegate boilerplate, CRUD operations, and test generation to AI systems like Copilot, allowing them to have time for higher-level design work.
- Pull request workflows have accelerated since AI can assist with code review comments, summaries, and merge checks.
- Copilot Studio has agents that can (on their own) handle tasks like legal contract review, routing, and document classification. For example, Unifi, North America's largest aviation ground handling services provider, used Copilot Studio to reduce contract processing from days to minutes (https://www.microsoft.com/en-us/microsoft-copilot/blog/copilot-studio/new-and-improved-agent-governance-intelligent-workflows-and-connected-app-experiences/).

### Advantages

- **Adoption**: GitHub Copilot reached 20 million users by July 2025, with 90% of Fortune 100 companies using it (https://www.quantumrun.com/consulting/github-copilot-statistics/).
- **Productivity**: Experiments among 4,800 developers (conducted by GitHub in partnership with Accenture) showed tasks got completed 55% faster. Pull request cycle time dropped from 9.6 days to 2.4 days — a 75% reduction (https://www.quantumrun.com/consulting/github-copilot-statistics/).

### Limitations & Challenges

- AI-generated code needs to be carefully reviewed; about 70% of suggestions by AI are discarded or edited. (https://www.secondtalent.com/resources/github-copilot-statistics/)
- Productivity benefits are uneven: repetitive tasks like writing boilerplate, creating standard CRUD operations, and generating test cases might be accelerated, but complex reasoning tasks benefit far less. (https://www.secondtalent.com/resources/github-copilot-statistics/) 


## 4. Duolingo — AI-First Strategy & the Human Backlash

### How They Use AI

Duolingo said that it was "AI-first" in April 2025, announcing that it would switch to AI and that employees would be evaluated on their AI usage. (https://arvindmozumdar.medium.com/duolingos-ai-reckoning-how-a-memo-about-automation-ignited-a-firestorm-c29deeb56f50) 
On the product side, the internal "Bird Brain" personalisation engine customizes lessons to each user's performance and pace, and generative models helped accelerate the creation of 148 new language courses in under a year — something that would have taken much more eresources and taken longer with traditional methods.(https://www.cognitute.org/case-study/duolingo-transformation-into-learning-platform) 
Duolingo Max, its premium subscription tier, features "Explain My Answer", which functions on large language models. (https://www.cognitute.org/case-study/duolingo-transformation-into-learning-platform)

### Workflow Changes

- Engineers spend dedicated "Friday two-hour blocks" adapting to AI tools by learning and experimenting, with  learning materials developed to improve employees' understanding and application of AI. (https://www.itbrew.com/stories/2025/08/26/what-ai-first-looks-like-at-duolingo)
- Regular "AI assembly" lets engineers share prototypes, new tools, what works, and things that haven't worked. This way they can learn collectively. (https://www.itbrew.com/stories/2025/08/26/what-ai-first-looks-like-at-duolingo)

### Advantages

- Content creation speed: 148 new language courses developed in under a year using AI. (https://www.cognitute.org/case-study/duolingo-transformation-into-learning-platform)
- The "Explain My Answer" feature was used by 65% of users and increased course completion rates by 15%. (https://www.5dvision.com/post/case-study-duolingos-ai-powered-language-learning-revolution/)

### Limitations & Challenges

- AI-generated code is hard to debug: CEO Luis von Ahn acknowledged that code that is written by AI can be more difficult to debug and may be unreliable. (https://fortune.com/2026/04/13/duolingo-ceo-luis-von-ahn-ai-usage-requirement-employee-performance-evaluations/)
- Public backlash: The "AI-first" initiative, which planned to phase out contractors and accept "small hits on quality", quickly sparked intense backlash from users and linguists, who saw it as a betrayal of the brand. (https://arvindmozumdar.medium.com/duolingos-ai-reckoning-how-a-memo-about-automation-ignited-a-firestorm-c29deeb56f50)
- Black box tranparency: AI testing tools can be a "black box," forcing teams to be extra careful due to the compromised transparency. (https://www.frugaltesting.com/blog/how-does-duolingo-use-ai-for-software-testing-in-2025)
